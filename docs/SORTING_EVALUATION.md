# Mixed-item tote sorting — proposed evaluation

This is an illustrative plan, not a completed deployment or performance result.

Start with one source tote and three destination totes, an agreed set of small cartons, rigid containers and sealed pouches. Record SKU, dimensions, mass and allowed contact. Start with separated items before adding overlap or occlusion. Confirm arm, vision, routing, end-effector and recovery responsibilities.

A screening proposal is 10 agreed SKUs × 20 randomized attempts per candidate end effector. Compare a dexterous hand with suction or a parallel gripper under matching conditions. Report correct placements / initiated attempts, retained lifts / pick attempts, median and 95th percentile cycle time, damage, drops and manual assists. Include failures and recovery time. Agree thresholds before testing; this sample does not qualify production reliability.
